# Большое табло `HH:MM:SS` на ESP32 и TM1640

Это руководство рассчитано на самодельные цифры, каждая из которых собрана из семи сегментов `a…g` и необязательной точки `DP`. На каждый сегмент используется один обычный светодиод. Все цифры должны иметь конфигурацию с общим катодом.

## 1. Как найти первый вывод TM1640

На SOP28 первая ножка обычно обозначена одним или несколькими способами:

- круглой углубленной точкой возле вывода 1;
- выемкой на торце корпуса: если повернуть микросхему этой выемкой вверх, вывод 1 находится слева сверху;
- скошенным углом или меткой на корпусе;
- точкой, треугольником, `1` или скосом на шелкографии платы.

Нумерация идёт против часовой стрелки при виде на микросхему сверху. У TM1640 вывод 1 — `GRID12`, вывод 6 — `VSS/GND`, вывод 7 — `DIN`, вывод 8 — `SCLK`, вывод 17 — `VDD`.

На готовой плате нумерация внешнего разъёма может не совпадать с нумерацией микросхемы. Проверяйте надписи `5V`, `GND`, `CLK`, `DIN`. При сомнениях выключите питание и прозвоните мультиметром землю разъёма с выводом 6, а затем найдите цепь питания от вывода 17. Не подавайте питание до проверки.

## 2. Распиновка SOP28

| Вывод | Назначение | Вывод | Назначение |
|---:|---|---:|---|
| 1 | GRID12 | 28 | GRID11 |
| 2 | GRID13 | 27 | GRID10 |
| 3 | GRID14 | 26 | GRID9 |
| 4 | GRID15 | 25 | GRID8 |
| 5 | GRID16 | 24 | GRID7 |
| 6 | VSS / GND | 23 | GRID6 |
| 7 | DIN | 22 | GRID5 |
| 8 | SCLK | 21 | GRID4 |
| 9 | SEG1 | 20 | GRID3 |
| 10 | SEG2 | 19 | GRID2 |
| 11 | SEG3 | 18 | GRID1 |
| 12 | SEG4 | 17 | VDD / +5 В |
| 13 | SEG5 | 16 | SEG8 |
| 14 | SEG6 | 15 | SEG7 |

## 3. Что понадобится

- ESP32;
- TM1640 SOP28 или плата с ней;
- преобразователь уровней `74HCT245` или `74HCT125` с питанием 5 В;
- 6 цифр по 7 или 8 светодиодов;
- 4 светодиода для двух двоеточий;
- резисторы `220–330 Ом` для каждой SEG-линии;
- конденсаторы `100 нФ` и `47–100 мкФ`;
- источник 5 В с достаточным запасом по току.

Для шести цифр с DP и двух двоеточий требуется 52 LED. Без DP — 46 LED. TM1640 мультиплексирует разряды самостоятельно, поэтому все 52 LED не питаются одновременно.

## 4. Питание и управляющие сигналы

```text
                         +5 В
                           │
              ┌────────────┼────────────┐
              │            │            │
          ESP32 5V     74HCT245      TM1640 VDD
              │          VCC (20)       вывод 17
              │            │            │
             GND       GND (10)      VSS (6)
              └────────────┴────────────┘
                           │
                          GND
```

Возле TM1640:

```text
VDD (17) ──┬── 100 нФ ──┬── VSS (6)
           └── 100 мкФ ─┘
```

У ESP32 логика 3,3 В, а TM1640 при питании 5 В не гарантирует распознавание 3,3 В как высокого уровня. Поэтому между ESP32 и входами `DIN/SCLK` нужен HCT-буфер.

### 74HCT245

```text
VCC вывод 20 ──> +5 В
GND вывод 10 ──> GND
DIR вывод 1  ──> +5 В       (A → B)
/OE вывод 19 ──> GND        (выходы включены)

ESP32 GPIO25 ──> A1 вывод 2
                 B1 вывод 18 ──> TM1640 SCLK вывод 8

ESP32 GPIO26 ──> A2 вывод 3
                 B2 вывод 17 ──> TM1640 DIN вывод 7
```

Неиспользуемые входы A3–A8 подключите к GND. Обратный канал не нужен.

## 5. Одна цифра

```text
       a
      ───
   f │   │ b
      ───  g
   e │   │ c
      ───
       d
```

| Сегмент | TM1640 | Бит RAM |
|---|---|---:|
| a | SEG1, вывод 9 | 0 |
| b | SEG2, вывод 10 | 1 |
| c | SEG3, вывод 11 | 2 |
| d | SEG4, вывод 12 | 3 |
| e | SEG5, вывод 13 | 4 |
| f | SEG6, вывод 14 | 5 |
| g | SEG7, вывод 15 | 6 |
| DP | SEG8, вывод 16 | 7 |

Схема одного сегмента:

```text
SEG1 ──[330 Ом]─────▶|─────┐
                  анод LED  катод
                             │
                             └── общий катод цифры ──> GRID
```

Катоды нельзя подключать напрямую к GND: они должны идти на соответствующий GRID. Не используйте один общий резистор на катод всей цифры.

## 6. Объединение шести цифр

Одноимённые аноды всех цифр объединяются по SEG-линиям:

```text
SEG1 ──[330 Ом]──┬── a цифры H1
                 ├── a цифры H2
                 ├── a цифры M1
                 ├── a цифры M2
                 ├── a цифры S1
                 └── a цифры S2

SEG2…SEG8 подключаются аналогично.
```

Общие катоды не объединяются:

| Элемент | GRID | Вывод | RAM |
|---|---|---:|---|
| Десятки часов H1 | GRID1 | 18 | `ram[0]` |
| Единицы часов H2 | GRID2 | 19 | `ram[1]` |
| Первое двоеточие | GRID3 | 20 | `ram[2]` |
| Десятки минут M1 | GRID4 | 21 | `ram[3]` |
| Единицы минут M2 | GRID5 | 22 | `ram[4]` |
| Второе двоеточие | GRID6 | 23 | `ram[5]` |
| Десятки секунд S1 | GRID7 | 24 | `ram[6]` |
| Единицы секунд S2 | GRID8 | 25 | `ram[7]` |

## 7. Два двоеточия

```text
SEG1 ──[резистор]── верхняя точка первого и второго двоеточия
SEG2 ──[резистор]── нижняя точка первого и второго двоеточия

Катоды первого двоеточия ──> GRID3
Катоды второго двоеточия ──> GRID6
```

Если используется один резистор на общую SEG-линию, дополнительные резисторы у точек не нужны. Если резисторы стоят возле каждого LED, каждая точка должна иметь собственный резистор.

```c
ram[2] = 0x03; // первое двоеточие включено
ram[5] = 0x03; // второе двоеточие включено
```

## 8. Коды цифр

```c
static const uint8_t DIGITS[10] = {
    0x3F, // 0
    0x06, // 1
    0x5B, // 2
    0x4F, // 3
    0x66, // 4
    0x6D, // 5
    0x7D, // 6
    0x07, // 7
    0x7F, // 8
    0x6F  // 9
};
```

DP включается добавлением бита `0x80`:

```c
ram[0] = DIGITS[8] | 0x80;
```

## 9. Настраиваемое мигание двоеточий

В веб-интерфейсе следует предусмотреть настройку **«Двоеточие»** с вариантами:

- **Включено постоянно**;
- **Мигание 1 Гц**;
- **Выключено**.

Выбор сохраняется в NVS, чтобы восстанавливаться после перезагрузки. При режиме 1 Гц обновление выполняется каждые 100–200 мс, а точки включены первые 500 мс каждой секунды.

```c
void tm1640_show_time(int hour, int minute, int second,
                      bool colon_on)
{
    uint8_t ram[16] = {0};
    const uint8_t colon = colon_on ? 0x03 : 0x00;

    ram[0] = DIGITS[(hour / 10) % 10];
    ram[1] = DIGITS[hour % 10];
    ram[2] = colon;
    ram[3] = DIGITS[(minute / 10) % 10];
    ram[4] = DIGITS[minute % 10];
    ram[5] = colon;
    ram[6] = DIGITS[(second / 10) % 10];
    ram[7] = DIGITS[second % 10];

    tm1640_write_ram(ram);
}
```

Эта настройка является частью будущей поддержки TM1640 в прошивке; сама по себе схема подключения не добавляет пункт в существующую веб-панель.

## 10. Порядок первого запуска

1. Не подключайте LED. Проверьте 5 В между VDD и VSS.
2. Проверьте общий GND у ESP32, буфера и TM1640.
3. Подключите только одну цифру к GRID1.
4. По очереди запишите в `ram[0]` значения `0x01`, `0x02`, `0x04`, …, `0x80`. Должны последовательно зажигаться `a…g, DP`.
5. Проверьте цифры `0…9`.
6. Подключите двоеточие к GRID3 и проверьте `ram[2] = 0x03`.
7. Подключите остальные цифры и проверьте `12:34:56`.
8. Если яркость слишком высокая, увеличьте сопротивление или уменьшите программную яркость.

Если порядок сегментов отличается, измените таблицу битов в программе, не перепаивая всё табло.
