## RTC DS3231

DS3231 может сохранять ход времени при отключении основного питания ESP32. Для возможного подключения к текущей плате доступны стандартные выводы I²C:

- **SDA:** GPIO21;
- **SCL:** GPIO22;
- **питание и резервная батарея:** по документации конкретного RTC-модуля.

Прошивка обнаруживает DS3231 по адресу `0x68`, загружает время при запуске и записывает в RTC успешную синхронизацию NTP или ручную установку времени. Если модуль не обнаружен, устройство продолжает работать с системным временем и NTP.

Источники:

- [официальная страница DS3231 Analog Devices](https://www.analog.com/en/products/ds3231.html);
- [официальный datasheet DS3231](https://www.analog.com/media/en/technical-documentation/data-sheets/ds3231.pdf);
- [системное время и RTC в ESP-IDF](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/api-reference/system/system_time.html).
