# Монтажная схема ESP32 + TM1640 `HH:MM:SS` — без 74HCT245 и DP

Это обновлённый вариант с **прямым подключением GPIO25/26 к TM1640**, без десятичных точек и с монтажным рисунком вместо перегруженной принципиальной схемы.

- **`ESP32_TM1640_HHMMSS.pdf`** — векторный PDF на одной большой странице;
- **`ESP32_TM1640_HHMMSS.svg`** — масштабируемая и редактируемая версия;
- **`kicad/ESP32_TM1640_Clock.kicad_pro`** — редактируемый проект KiCad;
- **`ESP32_TM1640_KiCad.zip`** — архив проекта KiCad;
- `bom.csv` — 59 компонентов;
- `connections.csv` — 138 подписанных подключений;
- `generate_schematic.py` и `wiring_scene.py` — генераторы документов.

## Как устроен рисунок

Провода показаны цветами, компоненты — в монтажном стиле с выводами `A/K`, корпусами и обозначениями. Надписи разнесены и не перекрывают друг друга.

Чтобы не рисовать перекрёстные связи между всеми 46 LED и микросхемой, используются **одноимённые клеммы**:

- `SEG1…SEG7` на драйвере соединяются с одноимёнными клеммами всех LED-модулей;
- `GRID1…GRID8` подключаются каждый к своему модулю;
- цепь `SEGn_DRV` находится до резистора, а `SEGn` — после него;
- зелёные вертикальные линии в модулях объединяют катоды; точки на них обозначают реальные соединения;
- нарисованные провода не имеют перекрёстков без соединения.

Такой жгут можно собрать на разъёмах или клеммниках. Одноимённые клеммы представляют одну электрическую цепь даже когда провод между ними не протянут через весь лист.

## Подключение контроллера

| ESP32 | TM1640 | Назначение |
|---|---|---|
| GPIO25 | SCLK, вывод 8 | Тактирование, прямое соединение |
| GPIO26 | DIN, вывод 7 | Данные, прямое соединение |
| 5V | VDD, вывод 17 | Питание 5 В |
| GND | GND, вывод 6 | Общая земля |

Кнопка SW1 соединяет GPIO32 с GND. Рядом с TM1640 установлены C1 = 100 нФ и C2 = 47–100 мкФ. Десятичные точки, кнопка DP, SEG8 и восьмой резистор не используются.

**Важно:** при питании TM1640 от 5 В входной высокий уровень 3,3 В не гарантирован документацией. Прямое управление выполнено по вашему требованию без HCT-буфера; на реальном железе возможна нестабильная работа.

## Светодиодные модули

Всего используется 46 LED:

- шесть цифр по семь LED — `a,b,c,d,e,f,g`;
- два двоеточия по два LED;
- семь общих SEG-резисторов **ОМЛТ 510 Ом**.

Для одного зелёного LED при питании 5 В резистор 510 Ом обычно обеспечивает ток порядка 4–6 мА в зависимости от его прямого напряжения. Поскольку TM1640 мультиплексирует разряды, средняя яркость будет ниже, чем при постоянном подключении одного LED.

| Модуль | GRID | RAM |
|---|---:|---:|
| Десятки часов H1 | 1 | 0 |
| Единицы часов H2 | 2 | 1 |
| Первое двоеточие C1 | 3 | 2 |
| Десятки минут M1 | 4 | 3 |
| Единицы минут M2 | 5 | 4 |
| Второе двоеточие C2 | 6 | 5 |
| Десятки секунд S1 | 7 | 6 |
| Единицы секунд S2 | 8 | 7 |

Верхние точки двоеточий подключаются к SEG1, нижние — к SEG2. Катоды модулей идут только на свой GRID и не подключаются напрямую к GND.

## Открытие KiCad

1. Распакуйте `ESP32_TM1640_KiCad.zip`.
2. Откройте `ESP32_TM1640_Clock.kicad_pro` в KiCad.
3. Более новая версия может предложить обновить формат схемы KiCad 6 — подтвердите сохранение в новом формате.

Символы встроены в `.kicad_sch`; внешние библиотеки не нужны. В проекте 59 символов, 138 сетевых меток и 9 no-connect для SEG8 и GRID9…GRID16. Это схема, а не разводка PCB.

## Перегенерация

Готовые файлы не требуют Python. Для повторной генерации после изменений:

```bash
python3 -m pip install reportlab
python3 hardware/generate_schematic.py
```

После перегенерации нужно также обновить ZIP-архив проекта KiCad.

## Проверка

- визуальный просмотр PDF/SVG-сцены;
- автоматическая проверка bounding boxes: **0 пересечений между текстовыми надписями**;
- 46 уникальных LED и правильная нагрузка всех SEG/GRID;
- раздельные цепи на входе и выходе каждого из семи резисторов;
- независимый парсер `kiutils`: 59 символов, 138 меток, 9 no-connect и 7 встроенных библиотек;
- PDF, SVG XML, JSON и ZIP проходят структурные проверки.

Графический KiCad и ERC в sandbox не запускались.
