# Принципиальная схема ESP32 + TM1640 `HH:MM:SS`

Здесь находятся три версии одной схемы:

- **`ESP32_TM1640_HHMMSS.pdf`** — векторный PDF на одной большой странице; можно увеличивать без потери качества и печатать с масштабированием на A4/A3;
- **`ESP32_TM1640_HHMMSS.svg`** — редактируемая векторная версия для Inkscape, Illustrator или браузера;
- **`kicad/ESP32_TM1640_Clock.kicad_pro`** — редактируемый проект KiCad со схемой, компонентами, номерами выводов и сетевыми метками.

Дополнительно:

- `ESP32_TM1640_KiCad.zip` — архив проекта KiCad;
- `bom.csv` — перечень всех 68 компонентов;
- `connections.csv` — таблица электрических цепей с названиями и номерами выводов;
- `generate_schematic.py` — генератор всех форматов.

## Открытие в KiCad

1. Распакуйте `ESP32_TM1640_KiCad.zip` или откройте папку `hardware/kicad` в репозитории.
2. В KiCad выберите **Open Project** и откройте `ESP32_TM1640_Clock.kicad_pro`.
3. Откройте редактор схем. Исходник использует формат схемы KiCad 6 (`20211123`); более новая версия KiCad может предложить сохранить его в своём формате — подтвердите обновление.
4. Все символы хранятся внутри `.kicad_sch`, поэтому внешние библиотеки для открытия не нужны.

Это **проект принципиальной схемы**, без разводки печатной платы. Корпуса и посадочные места нужно выбрать перед созданием PCB с учётом фактически купленных компонентов.

## Что показано на схеме

- ESP32 с GPIO25/26 для TM1640 и GPIO32/33 для кнопок;
- полный 20-выводной 74HCT245 и полный 28-выводной TM1640;
- питание 5 В, общий GND, конденсаторы 100 нФ и 47–100 мкФ;
- восемь резисторов 330 Ом;
- 48 LED для шести цифр `a…g,DP` и 4 LED для двоеточий — всего 52;
- отдельные цепи `SEGn_DRV` от микросхемы до резистора и `SEGn` после резистора;
- GRID1…GRID8 для шести цифр и двух двоеточий;
- неподключённые GRID9…GRID16 и B3…B8, отмеченные символами no-connect.

### Распределение табло

| Элемент | GRID | RAM |
|---|---:|---:|
| Десятки часов H1 | 1 | 0 |
| Единицы часов H2 | 2 | 1 |
| Первое двоеточие C1 | 3 | 2 |
| Десятки минут M1 | 4 | 3 |
| Единицы минут M2 | 5 | 4 |
| Второе двоеточие C2 | 6 | 5 |
| Десятки секунд S1 | 7 | 6 |
| Единицы секунд S2 | 8 | 7 |

`SEG1…SEG8 = a,b,c,d,e,f,g,DP`. Верхние точки двоеточий используют SEG1, нижние — SEG2.

## Важно перед сборкой

- TM1640 и 74HCT245 питаются от **5 В**, земля всех частей общая.
- HCT-буфер согласует 3,3-вольтовые GPIO ESP32 с 5-вольтовыми входами TM1640. Не заменяйте его на 74HC245 без проверки входных порогов.
- Катоды цифр подключаются к GRID, а не напрямую к GND.
- Резисторы стоят в общих SEG-линиях; не ставьте один общий резистор в катод цифры.
- Конденсаторы размещаются рядом с выводами питания TM1640.
- Перед проектированием печатной платы проверьте фактические корпуса, шаг выводов и расположение контактов приобретённых модулей.

## Перегенерация

Готовые файлы открываются без Python. Генератор нужен только после изменения исходного описания:

```bash
python3 -m pip install reportlab
python3 hardware/generate_schematic.py
```

Для русских надписей требуется DejaVu Sans или Arial. После перегенерации архив KiCad нужно создать заново либо использовать файлы непосредственно из `hardware/kicad`.

## Проверка

SVG проверен как XML, PDF — как векторный одностраничный документ. KiCad-файл прочитан независимым парсером `kiutils`: 68 символов, 170 подписанных подключений и 14 no-connect. Таблица цепей проверена на 52 уникальных LED, ожидаемую нагрузку SEG/GRID и раздельные стороны каждого резистора. Графический KiCad и ERC в sandbox не запускались.
