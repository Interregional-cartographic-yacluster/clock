# ESP32 Clock — Wokwi с макетными платами

Проект для виртуального табло `ЧЧ:ММ:СС`: **ESP32 + ST7789 + DS3231 + TM1640**, **46 LED**, семь резисторов **ОМЛТ 510 Ом**. DP нет, 74HCT245 нет. TM1640 управляется непосредственно с ESP32.

## Открыть и запустить

1. Откройте [Wokwi](https://wokwi.com/), создайте **New Project → ESP32**.
2. В редакторе схемы нажмите синюю **«+» → Custom Chip → C**, введите имя **`tm1640`**. Этот шаг обязателен: он регистрирует custom chip в проекте.
3. Замените содержимое созданных `tm1640.chip.json` и `tm1640.chip.c` файлами этого каталога.
4. Замените `diagram.json` и `sketch.ino`, добавьте `libraries.txt`.
5. Нажмите **Start simulation**.

**Не достаточно просто скопировать два файла TM1640 в пустой проект:** сначала создайте custom chip через «+», как описано выше. Иначе Wokwi может не скомпилировать модель, и LED-табло не заработает.

Альтернативно распакуйте `clock-tm1640-wokwi.zip` и импортируйте эти файлы через редактор проекта. Для локального Wokwi CLI `diagram.json` и custom chip используются непосредственно; firmware/ELF в CLI задаётся вашей Arduino/PlatformIO-сборкой.

После запуска:

- первую секунду включаются все **46 LED** для ламп-теста;
- время DS3231 выводится одновременно на ST7789 и LED-табло;
- кнопка `C` (`GPIO32 → GND`): короткое нажатие — следующий город, удержание **5 с** — демонстрационный экран Wi-Fi setup; короткое нажатие на экране setup возвращает часы;
- Serial Monitor показывает действия и состояние RTC.

Это демонстрационная Arduino-прошивка Wokwi, не замена основной ESP-IDF-прошивки: Wi-Fi/captive portal, NTP и полноценная многоязычная логика реализованы в `main/clock.c`.

### Если экран пустой

1. Нажмите **Stop**, затем **Start simulation** после сохранения всех файлов.
2. Serial Monitor должен сразу показать `Breadboard clock starting...`, затем `ST7789 initialized...`. На TFT до обращения к RTC появляется оранжевая надпись **`CLOCK START`**.
3. Откройте вкладку **Chips Console**. Исправно загруженная модель выводит `TM1640 custom chip initialized`, затем `RAM data received` и `display ON`.
4. Если сообщения `custom chip initialized` нет, повторите регистрацию через **«+» → Custom Chip → C → tm1640** и замените созданные файлы. Ошибки компиляции отображаются в Chips Console.
5. Если нет даже первого сообщения Serial Monitor, проверьте, что выбран `sketch.ino` этого проекта и нет ошибок компиляции Arduino-библиотек.

## Макетные платы

Проект содержит **две `wokwi-breadboard-half`**:

- **BB1** — сигналы ESP32, питание периферии, ST7789, DS3231 и кнопка;
- **BB2** — TM1640, семь резисторов SEG1…7 и разъёмные линии GRID1…8 на LED-табло.

Провода не просто нарисованы между компонентами: сигналы проходят через реальные отверстия и внутренние ряды breadboard. Пять отверстий одной половины строки соединены внутри макетки; верхняя и нижняя половины разделены центральным каналом. Например, цепь SEG1:

```text
TM1640 SEG1 → BB2 1a…1e → R1 (510 Ω) → BB2 1f…1j → аноды LED SEG1
```

Здесь резистор стоит в **анодной** цепи SEG1. Катоды восьми LED строки H1 объединены через GRID1 на строке BB2 10. Остальные строки аналогичны. TM1640 включает один общий катод и выдаёт нужную комбинацию анодов; светодиоды соединены общим катодом, как требует даташит.

### Ключевые строки BB1

| Строка | Сигнал |
|---|---|
| 5 | GPIO25 → TM1640 SCLK |
| 6 | GPIO26 → TM1640 DIN |
| 10 | GPIO21 → DS3231 SDA |
| 11 | GPIO22 → DS3231 SCL |
| 12…16 | GPIO18/23/5/15/4 → ST7789 SCLK/MOSI/CS/DC/RST |
| 20 | GPIO32 → кнопка → GND |
| `tp` / `tn` | 5 V / GND для TM1640 и DS3231 |

ST7789 питается от 3.3 V (`VCC`, `BLK`). Виртуальная DS3231 — `wokwi-ds3231`, адрес `0x68`.

### TM1640 и резисторы BB2

| Цепь | Резистор | Строка | LED |
|---|---|---|---|
| SEG1 | R1 | 1 | все сегменты `a` + верхние точки двоеточий |
| SEG2 | R2 | 2 | все сегменты `b` + нижние точки двоеточий |
| SEG3…SEG7 | R3…R7 | 3…7 | сегменты `c`, `d`, `e`, `f`, `g` |

| GRID | Строка BB2 | Знакоместо | LED |
|---|---|---|---|
| GRID1 | 10 | H1 | D1…D7 |
| GRID2 | 11 | H2 | D8…D14 |
| GRID3 | 12 | C1 | D15, D16 |
| GRID4 | 13 | M1 | D17…D23 |
| GRID5 | 14 | M2 | D24…D30 |
| GRID6 | 15 | C2 | D31, D32 |
| GRID7 | 16 | S1 | D33…D39 |
| GRID8 | 17 | S2 | D40…D46 |

SEG8 не подключен. GRID9…GRID16 модели есть по распиновке SOP28, но в табло не используются.

## Файлы

| Файл | Назначение |
|---|---|
| `diagram.json` | Готовая breadboard-схема Wokwi |
| `generate_diagram.py` | Детерминированный генератор `diagram.json` |
| `sketch.ino` | Arduino-демонстрация RTC, ST7789, TM1640 и кнопки |
| `libraries.txt` | RTClib, Adafruit GFX, Adafruit ST7735 and ST7789 Library |

| `clock-tm1640-wokwi.zip` | Комплект для переноса в Wokwi |
| `validate_project.py` | Проверка распиновки, внутренних связей breadboard и LED-карты |

После изменения генератора:

```bash
python3 wokwi/generate_diagram.py
python3 wokwi/validate_project.py
python3 wokwi/package.py
```

## Ограничения симуляции

- Wokwi проверяет логические соединения и протокол, но **не моделирует реальные уровни, токи и падение напряжения на ОМЛТ**.
- В реальном устройстве TM1640 с `VDD=5 В` имеет `VIH ≥ 0,7·VDD = 3,5 В`, а ESP32 выдаёт только 3,3 В. Поэтому прямое управление **не гарантирует устойчивую работу реального железа**. Здесь показан требуемый вариант без 74HCT245, без необоснованного заявления об электрической совместимости.
- ST7789 284×76 и RTC доступны как штатные компоненты Wokwi; TM1640 реализован включённым custom chip и обновляет LED в цикле динамической индикации.
- Цвета проводов повторяют цепи: SEG1…7 — разные цвета, GRID — зелёные, SCLK — синий, DIN — фиолетовый, питание — красный/чёрный.
