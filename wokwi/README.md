# Виртуальное табло ESP32 + TM1640 для Wokwi

Проект позволяет собрать и запустить табло `HH:MM:SS` в браузере. В схеме можно передвигать компоненты, удалять и добавлять провода, менять GPIO и проверять работу без реального железа.

## Что входит

- ESP32 DevKit C V4;
- цифровая модель TM1640 SOP28: двухпроводной протокол, 16 байт RAM, команды режима/адреса/яркости и сканирование GRID;
- цифровая модель 74HCT245;
- 6 цифр по 8 LED (`a…g`, `DP`) и 4 LED для двоеточий — всего **52 LED**;
- 8 резисторов по 330 Ом, по одному на общую SEG-линию;
- кнопка режима двоеточий и кнопка десятичных точек;
- самостоятельная демонстрационная прошивка Arduino для ESP32 без внешних библиотек.

## Запуск в Wokwi

1. Откройте [новый проект ESP32 в Wokwi](https://wokwi.com/projects/new/esp32).
2. Замените содержимое автоматически созданных `sketch.ino` и `diagram.json` одноимёнными файлами из этой папки. Можно использовать **Upload File** и подтвердить замену либо скопировать текст в редактор.
3. Загрузите в проект четыре файла моделей:
   - `tm1640.chip.json`;
   - `tm1640.chip.c`;
   - `hct245.chip.json`;
   - `hct245.chip.c`.
4. Нажмите зелёную кнопку **Start the simulation**.

Для удобства все необходимые файлы также собраны в архиве `clock-tm1640-wokwi.zip`. Запускать `generate_diagram.py` и загружать его в Wokwi не требуется — готовый `diagram.json` уже входит в проект.

## Что должно произойти

1. На одну секунду включатся все 52 светодиода — проверка табло.
2. Появится время `12:34:56`, которое продолжит идти по секундам.
3. Двоеточия будут мигать с частотой 1 Гц: 500 мс включены, 500 мс выключены.
4. В Serial Monitor появятся режим работы и назначение кнопок.

### Управление

| Кнопка на схеме | Клавиша | Действие |
|---|---|---|
| `C: colon mode` | `C` | Постоянно включено → мигание 1 Гц → выключено |
| `D: decimal points` | `D` | Включить/выключить DP у всех шести цифр |

Клавиши работают, пока запущена симуляция и область схемы имеет фокус. Можно нажимать и сами виртуальные кнопки.

## Основные соединения

| Сигнал | ESP32 | 74HCT245 | TM1640 |
|---|---|---|---|
| Тактирование | GPIO25 | A1 → B1 | SCLK |
| Данные | GPIO26 | A2 → B2 | DIN |
| Питание | 5V | VCC, DIR | VDD |
| Земля | GND | GND, OE, A3…A8 | GND |
| Режим двоеточий | GPIO32 | — | — |
| Десятичные точки | GPIO33 | — | — |

Обе кнопки соединяют соответствующий GPIO с GND; в прошивке включены внутренние подтягивающие резисторы.

### Распределение табло

| RAM | GRID | Элемент |
|---:|---:|---|
| 0 | GRID1 | Десятки часов |
| 1 | GRID2 | Единицы часов |
| 2 | GRID3 | Первое двоеточие, биты `0x03` |
| 3 | GRID4 | Десятки минут |
| 4 | GRID5 | Единицы минут |
| 5 | GRID6 | Второе двоеточие, биты `0x03` |
| 6 | GRID7 | Десятки секунд |
| 7 | GRID8 | Единицы секунд |

`SEG1…SEG8` соответствуют `a,b,c,d,e,f,g,DP`. Аноды одноимённых сегментов объединены через общую SEG-линию; катоды каждой цифры идут на собственный GRID и не подключаются напрямую к GND.

## Как менять схему

В графическом редакторе Wokwi провода создаются щелчком по выводу компонента и последующим щелчком по выводу назначения. Компоненты перемещаются мышью. Если поменять GPIO управления в схеме, измените `PIN_SCLK` и `PIN_DIN` в начале `sketch.ino`.

`generate_diagram.py` нужен только для автоматического пересоздания всей схемы из исходного описания:

```bash
python3 generate_diagram.py
```

Ручные изменения после такого пересоздания будут перезаписаны.

## Ограничения симуляции

- Это цифровая модель: напряжения, ток LED, сопротивление и аналоговые пороги HCT не рассчитываются физически.
- На реальном устройстве обязательны общий GND, питание TM1640/HCT от 5 В, HCT-преобразование 3,3 → 5 В и конденсаторы `100 нФ + 47–100 мкФ` возле TM1640. Подробности — в `docs/TM1640_ESP32_HHMMSS.pdf`.
- `sketch.ino` — отдельная демонстрация для Wokwi. Основная ESP-IDF-прошивка часов пока не содержит драйвер TM1640 и веб-настройку мигания двоеточий; кнопки в симуляторе заменяют эту будущую настройку.
