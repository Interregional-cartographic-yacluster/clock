# КосмоКРЯК: Горизонтальные часы на ESP32-WROOM-32D

**Проект в рамках модуля «Микроконтроллерная инженерия на базе ESP32» поднаправления «Космическая систематика»**

**МХ «КРЯК» | Курское региональное отделение | Проект «Уютные регионы»**

---

## 📟 Описание

Данный проект — первый аппаратный шаг в рамках поднаправления **«Космическая систематика»**. Устройство представляет собой **цифровые горизонтальные часы** на базе микроконтроллера ESP32-WROOM-32D с цветным дисплеем ST7789 (284×76 пикселей).

### Принцип работы:
1. ESP32 подключается к Wi-Fi сети.
2. Запрашивает текущее время у NTP-сервера (`pool.ntp.org`).
3. Отображает время, дату и надпись «КосмоКРЯК» на дисплее.
4. Автономно обновляет показания каждую секунду.

Устройство предназначено для использования в учебных целях, а также как элемент демонстрационных стендов в рамках образовательной программы.

## 💻 Программное обеспечение

Проект разработан в среде **ESP-IDF** с использованием компонентов:
- **ESP-IDF** — официальный фреймворк Espressif
- **LVGL v8** — библиотека графического интерфейса
- **esp_lcd** — драйвер для дисплея ST7789
- **esp_netif / esp_wifi** — работа с сетью
- **NVS** — хранение настроек (в будущем)

## 🔧 Установка и настройка

### 1. Установка драйверов (для CP2102)

Скачайте драйверы: [CP210x Windows Drivers](https://clck.ru/3URwbn)

### 2. Установка ESP-IDF

Скачайте установщик: [https://dl.espressif.com/dl/eim/?tab=online](https://dl.espressif.com/dl/eim/?tab=online)  
(файл `eim-gui-windows-x64.exe`)

### 3. Сборка и прошивка проекта

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Interregional-cartographic-I-cluster/clock.git
   cd clock
   ```

2. Настройте Wi-Fi в файле `clock.c`:
   ```c
   #define WIFI_SSID      "ваш_SSID"
   #define WIFI_PASS      "ваш_пароль"
   ```

3. Соберите проект:
   ```bash
   idf.py build
   ```

4. Подключите плату и узнайте номер COM-порта (например, COM3).

5. Прошейте:
   ```bash
   idf.py -p COM3 flash
   ```

6. Запустите монитор порта для просмотра вывода:
   ```bash
   idf.py monitor
   ```

**Совет:** Для ESP-IDF можно совмещать команды:
```bash
idf.py -p COM3 clean flash monitor
```

### Если прошивка зависает на «Connecting...»

1. Зажмите и удерживайте кнопку **BOOT**.
2. Нажмите и отпустите кнопку **EN** (сброс).
3. Отпустите кнопку **BOOT**.
4. Повторите команду `idf.py -p COM3 flash`.
